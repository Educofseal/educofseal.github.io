## Como este site é feito

Um `index.html` e uma pasta `assets`. HTML, CSS e JavaScript puro. Sem framework, sem build, sem npm.

O topo é um campo de ondas de luz desenhado em `<canvas>`, na mesma linguagem do banner do perfil: fundo índigo e ondas que vão do ciano ao violeta, com brilho contido. Conforme você desce, o texto muda em quatro tempos, as ondas correm mais rápido enquanto a página se move e o feixe se fecha no final. O mouse empurra as ondas de leve. Quando o topo sai da tela, a animação para.

Quem prefere menos movimento, e celular deitado sem altura, recebe o mesmo fundo parado e o texto final de uma vez.

- Tudo num `index.html`, com CSS e JavaScript dentro
- Nenhum vídeo e nenhuma imagem no topo; as capturas dos projetos são WebP e carregam só quando chegam perto da tela

## Rodando localmente
